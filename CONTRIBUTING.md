# Участие в разработке

Помочь MyRecordCollection можно сообщением об ошибке, предложением улучшения, исправлением кода или документации. Обсуждения и pull request можно оформлять на русском языке.

## Ошибки и предложения

Перед созданием Issue проверьте, нет ли похожего обсуждения среди открытых и закрытых задач. Используйте шаблон сообщения об ошибке или предложения функции. Для разных проблем создавайте отдельные Issues.

Для ошибки укажите версию приложения и Android, модель устройства, шаги воспроизведения, ожидаемое и фактическое поведение. При необходимости приложите скриншот или фрагмент журнала. Не публикуйте пароли, OAuth-токены, cookies и личные данные.

Для новой функции опишите задачу пользователя и желаемое поведение. Крупные изменения лучше сначала обсудить в Issue.

## Подготовка проекта

1. Создайте fork репозитория и клонируйте его на компьютер.
2. Откройте проект в Android Studio и выполните настройку из [README.md](README.md#запуск-проекта).
3. Создайте отдельную ветку для изменения.

Для проверки интеграции нужен собственный аккаунт с доступом к Яндекс Музыке. Для debug-сборки ключ подписи релизов не требуется.

## Работа с кодом

- Следуйте стилю существующего Kotlin-кода и компонентов Jetpack Compose.
- Сохраняйте разделение интерфейса, бизнес-логики и доступа к данным. Описание архитектуры находится в [PROJECT_NOTES.md](PROJECT_NOTES.md).
- Ограничивайте pull request одной задачей; избегайте несвязанных правок и массового форматирования.
- При изменении поведения добавляйте или обновляйте подходящие тесты. Обновляйте документацию, если меняются запуск или возможности приложения.
- Не добавляйте в репозиторий токены, ключи подписи, пароли, локальные настройки SDK и результаты сборки.

## Проверка изменений

Для изменений кода выполните из корня проекта в PowerShell:

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

Если изменение затрагивает интерфейс или взаимодействие с Android, проверьте соответствующий сценарий на устройстве либо эмуляторе. Инструментальные тесты запускаются на подключённом устройстве:

```powershell
.\gradlew.bat connectedDebugAndroidTest
```

Для правок только документации достаточно проверить текст, ссылки и форматирование.

## Отправка pull request

1. Отправьте ветку в свой fork и откройте pull request в исходный репозиторий.
2. Опишите проблему, внесённые изменения и способ проверки. Если есть связанный Issue, добавьте ссылку.
3. Для изменений интерфейса приложите скриншоты или короткое видео.
4. Укажите проверки, которые не удалось выполнить, и причину.

Проект распространяется под [GNU GPL версии 3.0](LICENSE). Предлагайте только код и материалы, которые вы вправе распространять на совместимых с проектом условиях.
