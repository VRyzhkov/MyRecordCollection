# Управление ограничением 18+ в Яндекс Музыке

Дата исследования: 9 октября 2026 года.

## Результат

Функция «Ограничить контент для детей» существует в официальном клиенте. Подтверждённый запрос для переключения этой функции через OAuth API пока не найден. Это не доказывает отсутствие запроса: настройка может быть локальной либо использовать недокументированный протокол.

В неофициальном API есть `GET https://api.music.yandex.net/account/settings` и `POST` на тот же адрес. POST принимает параметры в `application/x-www-form-urlencoded`, авторизация — `Authorization: OAuth <token>`. Наличие общего метода изменения настроек само по себе не подтверждает возможность управления ограничением 18+.

Проверенная модель `UserSettings` не описывает настройку фильтра 18+. Признаки контента и ограничения доступа у объектов каталога не являются настройками аккаунта. Нельзя подставлять предположительные названия параметров и считать HTTP 200 доказательством изменения фильтра.

## Значение для MyRecordCollection

Приложение открывает альбом или плейлист в официальном клиенте либо браузере, а не воспроизводит треки самостоятельно. Поэтому фильтрация локального списка не гарантирует исключение 18+ при воспроизведении в Яндекс Музыке.

Рабочий переключатель пока не добавлен: без подтверждённого протокола он не сможет достоверно показывать и менять ограничение.

## Что нужно проверить дальше

1. Сравнить сетевые запросы официального клиента при включении и выключении «Ограничить контент для детей». Не сохранять токены, cookies и персональные данные в репозиторий.
2. Если запрос есть, установить адрес, метод, тело, тип авторизации и способ чтения текущего состояния. Если запроса нет, проверить, является ли настройка локальной для клиента.
3. Проверить на тестовом аккаунте, что повторное чтение подтверждает новое состояние и официальный проигрыватель действительно пропускает помеченные треки. Отдельно проверить применение настройки на другом устройстве и после перезапуска клиента.
4. При поддержке используемой OAuth-авторизации реализовать независимый клиент настроек, обработку ошибок и синхронизацию при возврате в приложение.

## Требования к интерфейсу после подтверждения протокола

- Большой переключатель «18+» в углу противоположном списку треков: справа сверху в горизонтальной ориентации.
- Явные подписи «18+ разрешено» / «18+ заблокировано», чтобы исключить неоднозначность переключателя.
- Состояние берётся из подтверждённого ответа сервера; до загрузки и во время изменения управление недоступно.
- При ошибке не показывать неподтверждённое новое состояние; дать повторить запрос.
- Учесть расположенное справа сверху меню настроек и длинные заголовки альбомов.
